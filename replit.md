# Project Q — Quantitative Finance Toolkit

## Overview
Factor model analysis web application using Fama-French methodology. Users input stock tickers and date ranges to run factor decomposition analysis with interactive charts.

## Architecture
- **Backend**: FastAPI (Python) serving REST API and static files on port 5000
- **Frontend**: React + Recharts, built with Vite, output to `api/static/`
- **Core Library**: `project_q/` Python package for factor model computation

## Project Structure
```
api/main.py          - FastAPI endpoints (/api/health, /api/analyze)
api/static/          - Built frontend assets (generated by vite build)
frontend/            - React source (App.jsx, App.css, vite.config.js)
project_q/
  data/
    fama_french.py   - Fetches FF factors from Ken French's data library
    returns.py       - Fetches stock returns via yfinance
  factors/
    model.py         - FactorModel class (OLS regression, betas, alphas)
    analysis.py      - Variance attribution, plotting utilities
tests/               - Pytest tests with synthetic data
run.sh               - Startup script (builds frontend if needed, starts uvicorn)
```

## Key Dependencies
- Python: numpy, pandas, scipy, statsmodels, yfinance, matplotlib, seaborn, fastapi, uvicorn
- Node.js: react, react-dom, recharts, vite

## Development Notes
- Frontend build output goes to `api/static/` (configured in vite.config.js)
- `pandas_datareader` was replaced with direct HTTP fetching from Ken French's data library due to pandas 2.x incompatibility
- Server runs on port 5000 (Replit webview requirement)
- PYTHONPATH is set in run.sh to make `project_q` importable
